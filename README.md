## dreve-portfolio

닥터이브(Dr.Eve) 자사몰 메인 페이지를 다시 기획해 본 **비공식 포트폴리오 시안**입니다. 실제 닥터이브(주식회사 퍼포즈드) 사이트가 아니며 주문·결제·회원가입은 동작하지 않습니다.

- 여는 법: `dreve-portfolio/index.html`을 브라우저로 열기 (모바일 화면 기준으로 설계)
- 개선 포인트: 맨 위 '개선 포인트 보기' 버튼, 또는 주소 끝에 `#notes`
- 주요 개선: 고민 퀴즈로 맞는 차 추천, 색 이름·기능 이름 함께 표기, 후기 숏폼 자리, 원물 소개, 모바일 하단 고정 버튼
- 기획: 장민욱 / 구현: Claude Code 활용
- 상품명과 가격은 2026년 10월 30일 dreve.co.kr 화면을 참고했습니다.
